# 🎮 20 Minutes Until Dawn

A game development project inspired by **20 Minutes Till Dawn**, a survival game where players fight against waves of enemies and try to survive in an increasingly challenging environment.

This project was developed using Java and the LibGDX framework as a game development project.

## 📌 Overview

The project explores the implementation of a survival-oriented game, combining gameplay mechanics, player interactions, enemy encounters, and game state management.

The main goal was to design and implement a playable game while gaining practical experience in software development, game architecture, and interactive application design.

## ✨ Project Goals

- Implement core gameplay mechanics for a survival game.
- Develop player interactions and gameplay logic.
- Organize game components using a structured software design.
- Work with the LibGDX framework for game development.
- Practice object-oriented programming and game architecture.

## 🛠️ Technologies

- **Language:** Java
- **Framework:** LibGDX
- **Development Focus:** Game Development, Object-Oriented Programming, Gameplay Logic

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have:

- A compatible Java Development Kit (JDK).
- The project’s required LibGDX dependencies.
- A compatible Java IDE or build environment.

### Running the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Negar2006/untillDown.git
   ```

2. Open the cloned project in your preferred Java IDE.

3. Navigate to the project directory:

   ```text
   20-Minutes-Until-Dawn-Libgdx-AP-Spring-04-master/
   ```

4. Import the project and resolve its dependencies according to the included build configuration.

5. Run the appropriate desktop launcher or main application entry point.

> **Note:** The exact build and execution steps depend on the project's configuration and available launcher files.
